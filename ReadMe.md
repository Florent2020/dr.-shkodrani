# 🦷 Dr. Shkodrani — Dental Clinic Website

Modern dental clinic website built with React and styled-components, focused on premium UI design, responsive layouts, smooth user experience, and professional medical branding.

🌍 Live Website:  
👉 https://dr-shkodrani.vercel.app/

---

## ✨ About The Project

This project was designed and developed as a modern dental clinic website with a clean and professional visual identity.

The website focuses on:

- Modern healthcare UI/UX
- Responsive design for all devices
- Smooth animations & transitions
- Professional branding
- Patient-friendly experience
- Fast loading performance

The goal was to create a premium and trustworthy online presence for a dental clinic using modern frontend technologies.

---

## 🛠️ Built With

## 🚀 Installation

Clone the project:

```bash
git clone https://github.com/Florent2020/dr.-shkodrani.git
```

Go to the project directory:

```bash
cd dr.-shkodrani
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm start
```
